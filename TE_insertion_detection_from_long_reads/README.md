
# TE insertion detection from long reads

Because TEs are often polymorphic among individuals, not all TE insertions are expected to be represented in the genome assemblies. 

To obtain a more comprehensive view of TE insertions, we analysed the long-read sequencing data using [Sniffles2](https://github.com/fritzsedlazeck/Sniffles), a structural variant detection tool designed for long-reads. This analysis specifically focused on detecting insertions corresponding to the P-element, Shellder, and Spoink.

Structural variant calls generated by Sniffles2 were screened for insertion variants, and insertion sequences were extracted when available in the VCF records. These sequences were compared against a TE library (P-element, Shellder, and Spoink) using BLAST. For candidate insertions assigned to these elements, the surrounding genomic regions were further analysed to identify target-site duplications (TSDs) associated with the insertions.

## 1 - Pipeline overview

The detection and characterisation of TE insertions from long-read data were performed in four main steps. Paths correspond to the original analysis environment and must be adapted if the scripts are reused.

### 1.1 - Step 1. Mapping reads and structural variant detection

[01_run_map_and_sniffles.sh](scripts/01_run_map_and_sniffles.sh)

Nanopore reads from each strain were mapped to the *Drosophila simulans* reference genome using minimap2, processed with samtools, and analysed with Sniffles2 to detect structural variants. This step generated per-strain BAM files, per-strain SV callsets, and a combined population-level VCF.

##### Inputs:

-   Reference genome: *Drosophila simulans* Prin_Dsim_3.1 (GCA_016746395.2)

-   Nanopore filtered reads

##### Outputs:

The script generates the following directory structure:

```{r, eval=FALSE}
SV_Sniffles2/
├── bam/
│   ├── sample.sorted.bam
│   └── sample.sorted.bam.bai
│
└── sniffles2/
    ├── sample.vcf
    ├── sample.snf
    ├── population.snf
    └── population.vcf
```

### 1.2 - Step 2. Extraction and TE classification of insertion sequences

[02_identify_TE_insertions.sh](scripts/02_identify_TE_insertions.sh)

Insertion variants were screened from the Sniffles2 VCF files. Insertions with available sequence in the ALT field were extracted, compared against a TE database (P-element, Shellder and Spoink sequences) using [BLAST](https://www.sciencedirect.com/science/article/pii/S0022283605803602?via%3Dihub) (--min_ident 80, --min_aln_len 80), and summarised the results into TE-specific tables.

##### Helper scripts used in this step:

-   [extract_ins_from_vcf.sh](scripts/extract_ins_from_vcf.sh)

-   [classify_ins_and_make_tables_blast.py](scripts/classify_ins_and_make_tables_blast.py)

##### Inputs:

-   Structural variant VCF files produced in Step 1: `SV_Sniffles2/sniffles2/*.vcf`

-   TE library containing P-element, Shellder and Spoink sequences: `TE_all.fa`

##### Helper script:

-   [extract_ins_from_vcf.sh](scripts/extract_ins_from_vcf.sh)

##### Outputs:

```{r, eval=FALSE}
TE_INS_tables_blast/
├── work/
│   ├── sample.ins.fa
│   ├── sample.ins.meta.tsv
│   └── sample.TE.blast.tsv
│
└── tables/
    ├── sample.<TE>.tsv
    └── sample.UNCLASSIFIED.tsv
```

### 1.3 - Step 3. TSD detection

[03_detect_TSDs.sh](scripts/03_detect_TSDs.sh)

For each strain and TE-specific table, the candidate insertion sequences were compared with the reference genome to identify potential TSDs for P-element, Shellder, and Spoink. For each insertion, the script extracts the nucleotides from both ends of the insertion, using the expected TSD length (8 bp for the P-element and 4 bp for Shellder and Spoink). It also retrieves the reference genome sequence immediately upstream and downstream of the insertion site using [samtools](https://github.com/samtools/samtools) faidx, extracting the same number of nucleotides on either side. These sequences are written to an intermediate table that contains the candidate insertion ends and the corresponding genomic flanking sequences.

##### Inputs:

-   Insertion FASTA files from Step 2: `TE_INS_tables_blast/work/*.ins.fa`

-   TE-specific tables from Step 2: `TE_INS_tables_blast/tables/*.tsv`

-   Reference genome: *Drosophila simulans* Prin_Dsim_3.1 (GCA_016746395.2)

##### Helper scripts:

-   [extract_tsd.py](scripts/extract_tsd.py)

##### Outputs:

```{r, eval=FALSE}
TE_INS_tables_blast/
└── tsd_checks/
    ├── sample.P_element.tsd.tsv
    ├── sample.Shellder.tsd.tsv
    └── sample.Spoink.tsd.tsv
```

### 1.4 - Step 4. Integration of TSD information into TE insertion tables

[04_summarise_TSD_results.sh](scripts/04_summarise_TSD_results.sh)

This script compares the TSD candidate sequences extracted in Step 3. Specifically, it compares the first and last nucleotides of the insertion with the upstream and downstream genomic sequences around the insertion site to determine whether they form a conserved target-site duplication. If a match is detected, the TSD sequence is retrieved; otherwise, the insertion is labelled as non-conserved. The result is written as a new TSD column in the final TE insertion tables.

##### Input:

-   TE-specific tables from Step 2: `TE_INS_tables_blast/tables/*.tsv`

-   TSD tables from Step 3: `TE_INS_tables_blast/tsd_checks/*.tsv`

##### Helper script:

-   [merge_tsd_simple.py](scripts/merge_tsd_simple.py)

##### Output:

```{r, eval=FALSE}
tables_with_TSD/
├── sample.P_element.tsv
├── sample.Shellder.tsv
└── sample.Spoink.tsv
```
These files were also concatenated creating a single file for each strain: `*.allTE.tsv`
